# Local Model Web Studio

Deze kleine localhost-webapp toont de modelcatalogus uit `../models.json`, valideert model-ID's, vereist expliciete downloadbevestiging en accepteert geen willekeurige bestandspaden vanuit de browser.

De backend is Flask wanneer `arclm[web]` of `flask` is geïnstalleerd. In deze omgeving ontbreekt Flask, dus runtime is niet lokaal geverifieerd.
