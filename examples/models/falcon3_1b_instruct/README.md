# Falcon3 1B Instruct

Dit voorbeeld gebruikt `tiiuae/Falcon3-1B-Instruct`, een instructiemodel uit de Falcon3-familie met meertalige metadata voor onder andere Engels, Frans en Spaans.

De map bevat entrypoints voor vereisten, expliciete download, lokaal laden, generatie, datasetvoorbereiding, SFT, evaluatie, benchmark, opslag, offline herladen, security en chatformattering. Alleen metadata/security is in deze sessie gecontroleerd.

Gebruik `01_check_requirements.py` voordat je downloadt. Download met `02_download_model.py --allow-download`. Dataset: `data/falcon3_1b_instruct`. Beperkingen: geen lokale load/SFT/Agent-verificatie en geen taal-kwaliteitstest uitgevoerd.
