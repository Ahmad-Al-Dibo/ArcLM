# Modeldatasets

Deze map bevat kleine synthetische datasets voor de modelvoorbeelden. De records zijn bedoeld voor verificatie, preview en tiny-run SFT, niet voor kwaliteitsclaims.

Elke modelmap bevat een `dataset_metadata.json`, een trainingssplit, een validatiesplit en een benchmarksplit. De datasets bevatten geen persoonlijke informatie, secrets of verborgen redeneringen.
