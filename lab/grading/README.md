# ArcLM Lab Grading

The Lab grades readiness, not memorized output. From-scratch challenges use
small deterministic public tests and a rubric that rewards correctness, edge
cases, API discipline, code quality, learner tests, and explanation.

Architecture challenges use a different rubric because several designs may be
valid. They are scored on technical correctness, trade-off analysis, failure
handling, compatibility, and clarity.

No grader may require network access, GPU hardware, arbitrary local paths, or
production ArcLM code changes.
