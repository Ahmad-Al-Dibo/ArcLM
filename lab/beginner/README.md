# Beginner Lab

Small building blocks: records, cleaning, validation, vocabularies, tokenization, sequence preparation, and counters.

## Challenges

- `beginner-01-data-loading` - Load safe local records (data, from_scratch)
- `beginner-02-text-cleaning` - Clean text deterministically (preprocessing, from_scratch)
- `beginner-03-dataset-validation` - Validate dataset records (data, from_scratch)
- `beginner-04-vocabulary` - Build a deterministic vocabulary (tokenization, from_scratch)
- `beginner-05-word-tokenizer` - Implement a tiny word tokenizer (tokenization, from_scratch)
- `beginner-06-sequence-preparation` - Prepare causal LM sequences (training, from_scratch)
- `beginner-07-training-counters` - Track training progress (training, from_scratch)
- `beginner-08-beginner-capstone` - Build a tiny dataset inspector (data, from_scratch)

## Run

`python -m lab.runner test-level beginner`
