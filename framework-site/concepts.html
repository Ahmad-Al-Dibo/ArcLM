Core concepts

Concepts a developer needs before using ArcLM seriously. Each concept maps to real modules — not abstract marketing terms.

Record

A record is a plain Python dict of fields for one training or evaluation example. The conventional text field is "text". SFT also uses messages, prompt/completion, or instruction/output.

Where: arclm.datasets, JSONL files. Problem solved: uniform data interchange without a ORM.

records = [{"text": "Hello world"}, {"text": "ArcLM is light"}]

Config vs TrainingConfig

arclm.configs.Config is the broad workflow bag (model size, paths, device, tokenizer type). arclm.training.TrainingConfig is a small validated dataclass for the modern Trainer (epochs, precision, optimizer, …). They are intentionally different types. 

from arclm.configs import create_config
from arclm.training import TrainingConfig

cfg = create_config(embed_dim=32, device="cpu")
tcfg = TrainingConfig(epochs=3, batch_size=8, precision="fp32")

Tokenizer

Converts text to integer ids. ArcLM ships a word-level tokenizer (whitespace, inspectable vocab) and a SentencePiece subword tokenizer. No automatic lowercasing — normalize yourself if needed. 

from arclm.tokenizers import Tokenizer
tok = Tokenizer(max_vocab=64)
tok.build("your corpus ...")
ids = tok.encode_text("some words")

Optional torch

import arclm and light subpackages do not import torch. Importing arclm.models / arclm.training without torch raises OptionalDependencyError telling you to pip install "arclm[train]". 

import arclm, sys
print("torch" in sys.modules)  # False

Block (trimmed edition)

A Block is a generated package that contains only a subset of ArcLM modules (e.g. core-only or agents-only). Produced from the same source by tools/build_arclm_distributions.py. Install Blocks instead of full ArcLM, not alongside it.

Agent tool

A typed Python function wrapped by @tool. Type hints become a JSON schema; the docstring becomes the description for the model. Tools run inside a bounded AgentRunner loop with permissions. 

from arclm.agents import tool

@tool(category="utilities")
def add_numbers(left: float, right: float) -> float:
    """Add two numbers."""
    return left + right

Run (tracking)

A run is a directory under a tracking root with a manifest, metrics JSONL, and events. Created via arclm.tracking.create_run(RunConfig(...)). Private paths in manifests are redacted to <path omitted>.

Checkpoint

A serialized training state (weights + optional tokenizer/config metadata). Save with atomic_save_checkpoint; load trusted checkpoints with safe_load_training_checkpoint. Compatibility helpers refuse empty configs for resume/fine-tune.

Hugging Face model handle

load_any_model(source) returns an ExternalLoadedModel with .predict, .generate, and .chat. Chat uses the tokenizer—™s chat_template when present. Not every Hub model is supported.

Extra

A pip extra (e.g. arclm[train]) installs optional dependencies and unlocks packages that require them. Errors name the exact extra when something is missing.
