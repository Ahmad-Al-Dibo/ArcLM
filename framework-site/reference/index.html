ArcLM

ArcLM is a compact Python toolkit for language-model data workflows, tokenizers, optional PyTorch training, Hugging Face inference, agents, and security helpers.

What ArcLM is

The core install is light (~50 MB: NumPy + SentencePiece). PyTorch is optional and only required for native models, training, evaluation, and checkpoint tensor operations. Install it with the train extra. 

pip install arclm            # core
pip install "arclm[train]"   # + PyTorch

The design goal is a library you can read: small modules, explicit errors, CPU-first examples, and honest limits (the native model is a teaching model, not a production chat LLM).

Audience

  • Educators and students — laptop, no GPU cluster.
  • Application developers — load HF models, agents, data pipelines.
  • Researchers — embed a light toolkit; train only when needed.

What ArcLM is not

  • Not a replacement for Hugging Face as a model zoo.
  • Not a competitive large language model by itself.
  • Not a production multi-GPU serving stack.
