Errors & exceptions

All domain errors inherit from arclm.exceptions.ArcLMError.

OptionalDependencyError

Raised when a feature needs an extra that is not installed. The message names the package and the pip extra.

from arclm.exceptions import OptionalDependencyError
try:
    from arclm.models import ArcLM
except OptionalDependencyError as e:
    print(e)
# arclm.models requires optional dependency 'torch'.
# pip install "arclm[train]"

Handling patterns

from arclm.exceptions import ArcLMError, DatasetLoadError

try:
    records = load_dataset("missing.jsonl")
except DatasetLoadError as e:
    print("Dataset problem:", e)
except ArcLMError as e:
    print("ArcLM error:", e)
