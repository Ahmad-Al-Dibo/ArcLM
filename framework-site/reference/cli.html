Command-line interface

Entry points: arclm and python -m arclm.

Commands (verified via arclm --help)

CommandPurposeTorch?
versionPrint versionno
infoSafe runtime infono
doctorDiagnostics (no downloads)no
config validate|show|migrateTyped config toolsno
data validate|analyze|split|…Dataset toolsno
runsInspect local runsno
cacheInspect/clear cachesno
security status|auditSecurity inventoryno*
trainTrain / fine-tuneyes
evalEvaluate checkpointyes
generateGenerate textyes
chatInteractive chatyes
runConfig-driven workflowtypically
web-apiFastAPI Studioweb extra

*Some security crypto paths need cryptography.

Examples

arclm --version
arclm doctor
arclm doctor --json
arclm security status --json

arclm train --config config.yaml --data data.txt --output models/model.pth
arclm train --embed-dim 64 --num-blocks 2 --data data.txt --epochs 5 --device cpu
arclm eval --model models/model.pth --data test.txt --output metrics.json
arclm generate --model models/model.pth --prompt "hello" --length 50 --temperature 0.8
arclm chat --model Qwen/Qwen2.5-0.5B-Instruct --device cpu --system-prompt "Be concise."
python -m arclm web-api --host 127.0.0.1 --port 8765

Missing torch

Train/eval/generate/chat print a clear hint: pip install "arclm[train]".
