Package map

Conceptual layers

ArcLM exposes domain packages rather than three separate products. In practice, three usage paths map onto those packages:

PathTypical APIsAudience
Lab train_model, load_dataset, CLI Classrooms, first experiments
Developer Trainer, Config, checkpoints, agents, web API Application builders
Research Native model internals, tracking, search, inspection Experimentation and extension

Optional PyTorch

The root package uses a lazy export map. import arclm does not import torch. Torch-backed modules call require_torch() before importing torch and raise OptionalDependencyError with an install hint if torch is missing. 

import arclm
import sys
print("torch" in sys.modules)  # False

from arclm.tokenizers import Tokenizer
print("torch" in sys.modules)  # still False

from arclm.models import ArcLM  # requires arclm[train]

Package map

Core (torch-free)

  • arclm.configs — configuration objects and YAML/JSON IO
  • arclm.datasets — load, validate, clean, deduplicate
  • arclm.tokenizers — word-level and SentencePiece
  • arclm.security — crypto, redaction, signing, policies
  • arclm.agents — tools, runner, sessions
  • arclm.tracking — local run manifests and seeds
  • arclm.search — hyperparameter search (not IR search)
  • arclm.logics — propositional logic utilities
  • arclm.exceptions — error hierarchy
  • arclm.registry, arclm.utils

Training stack (needs [train])

  • arclm.models — native ArcLM GPT
  • arclm.training — Trainer, pipeline, regularization
  • arclm.inference — generation and HF loading
  • arclm.finetuning — SFT workflows
  • arclm.checkpoints — save/load/adapt
  • arclm.evaluation — metrics and diagnostics
  • arclm.peft — LoRA / QLoRA
  • arclm.inspection — pipeline traces

Error contract

Domain errors inherit from ArcLMError. Missing optional dependencies raise OptionalDependencyError with a message that names the extra (train, hf, …).

Blocks

distributions/ contains manifests that generate trimmed editions (core, training, agents, security, …) from the same source using AST import analysis and hard exclude boundaries. Blocks are alternatives to the full package, not add-ons.
