Installation

Core install (light)

Required dependencies: numpy and sentencepiece only. Typical size on the order of tens of megabytes. No PyTorch. 

python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install arclm

python -c "import arclm; print(arclm.get_version())"
# 2.0.0

CPU-only PyTorch

Install the CPU wheel first if you do not want a CUDA build: 

pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install "arclm[train]"

CUDA PyTorch

Match the wheel to your CUDA toolkit (example for CUDA 12.4): 

pip install torch --index-url https://download.pytorch.org/whl/cu124
pip install "arclm[train]"
arclm doctor   # verify CUDA available

From source

git clone https://github.com/Ahmad-Al-Dibo/ArcLM.git
cd ArcLM
pip install -e ".[dev,train]"

ArcLM Blocks (trimmed editions)

Alternative installs that ship only a subset of packages (core, training, agents, security, …). Generated from the same source. See distributions/README.md in the repository. 

pip install "git+https://github.com/Ahmad-Al-Dibo/ArcLM.git#subdirectory=distributions/core"

Verify the install

arclm --version
arclm doctor
python -c "from arclm.tokenizers import Tokenizer; print(Tokenizer)"
