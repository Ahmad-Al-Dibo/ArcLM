Troubleshooting

OptionalDependencyError: torch

You imported a training/model package without torch.

pip install "arclm[train]"
# or CPU wheel first:
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install "arclm[train]"

device="cuda" but no GPU

ArcLM fails loudly. Check arclm doctor. Install a CUDA torch build matching your drivers, or use device="cpu".

Too many <UNK> tokens

Tokenizer vocab is too small or built on the wrong corpus. Rebuild on representative text; consider SentencePiece.

Sequence longer than block_size

Native ArcLM forward rejects T > block_size. Slice tokens or increase block_size (and retrain).

HF model fails to load

  • Missing transformers → pip install "arclm[hf]"
  • Network / Hub outage
  • Gated model → set HF token in the environment (never hard-code)
  • Architecture not supported by ArcLM—™s HF path — try another model

Checkpoint incompatible

As of 2.0, checkpoints with a missing/empty config are never treated as compatible for resume/fine-tune. Re-save with ArcLM trainer APIs.

deduplicate return value confusing

Use deduplicate(records, return_result=True) and read .dataset, .kept, .removed.

arclm.search is not text search

It is hyperparameter search. For document search, use your own index or an external library.
