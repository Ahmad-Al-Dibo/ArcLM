Quick start

Three short paths: core only, training, and Hugging Face inference.

Path A — Core only (no PyTorch)

pip install arclm
from arclm.configs import Config, create_config
from arclm.tokenizers import Tokenizer
from arclm.datasets import load_dataset, validate_records, deduplicate
from arclm.security import redact_sensitive_text

config = create_config(embed_dim=32, block_size=16, device="cpu")
print(config.embed_dim)  # 32

text = "arc lm trains tiny models on local text about language models"
tok = Tokenizer(max_vocab=64)
tok.build(text)
print(tok.encode_text("arc lm trains"))  # e.g. [2, 3, 4]
print(tok.get_vocab_size())

records = load_dataset([
    {"text": "Hello world"},
    {"text": "Hello world"},
    {"text": "ArcLM is light"},
])
result = validate_records(records, required_fields=["text"])
print(result.valid_count)  # 3
out = deduplicate(records, return_result=True)
print(out.kept, out.removed)  # 2 1

print(redact_sensitive_text("api_key=sk-test-123"))
# api_key=[REDACTED]

Path B — Native tiny model

pip install "arclm[train]"
import torch
from arclm.models import ArcLM
from arclm.tokenizers import Tokenizer

text = "arc lm trains tiny models on local text about language models"
tok = Tokenizer(max_vocab=64)
tok.build(text)

model = ArcLM(
    vocab_size=tok.get_vocab_size(),
    embed_dim=16,
    block_size=8,
    num_blocks=1,
)
ids = torch.tensor([tok.encode_text("arc lm trains")[:8]])
logits = model(ids)
print(tuple(logits.shape))       # (1, 3, 11) on the sample text
print(model.get_num_parameters())
The native ArcLM model is intentionally tiny and educational. It is not a general-purpose chat model.

Path C — Hugging Face model

pip install "arclm[hf]"
from arclm.inference import load_any_model

model = load_any_model(
    "sshleifer/tiny-gpt2",
    device="cpu",
    trust_remote_code=False,
)
print(model.predict("Hello", max_new_tokens=5))
print(model.chat([{"role": "user", "content": "Hi"}], max_new_tokens=6))

First call downloads weights into the Hugging Face cache. Use a small public model for experiments. Gated models need a token; do not hard-code secrets.

CLI check

arclm doctor

Prints version, Python, torch (if present), CUDA, and optional dependency status without requiring torch.
