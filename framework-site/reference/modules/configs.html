arclm.configs core

Configuration objects and YAML/JSON persistence. When to use: any workflow that stores model size, data paths, device, tokenizer type, or training hyperparameters. When not to use: for the small TrainingConfig used by arclm.training.Trainer (that is a separate dataclass in arclm.training.config).

class Config

class Config(**kwargs)
Purpose Broad configuration bag for ArcLM workflows.
Params **kwargs — optional overrides for known attribute names.
Returns A Config instance.
Errors Unknown keys passed to create_config raise ValueError; set_safe ignores unknown keys with a warning.

Important attributes (defaults from source)

AttributeDefaultRole
embed_dim64Model embedding size
block_size8Context length
batch_size64Training batch size
num_epochs100Epochs for high-level train paths
vocab_sizeNoneSet after tokenizer build
learning_rate1e-3Optimizer LR
device"cpu"Compute device string
seed42Reproducibility seed value
tokenizer_type"word""word" or SentencePiece settings
model_path"output/model.pth"Checkpoint path
data_path"data/data.txt"Training data path
create_config() does not call torch.manual_seed. Seed with arclm.tracking.set_reproducible_seed if needed. Device defaults to "cpu", not auto-CUDA.

create_config(**kwargs) -> Config

create_config(**kwargs) -> Config
Purpose Build a Config from the full default set plus overrides.
When to use Prefer over raw Config() when you want the documented default surface.
Errors ValueError if any kwarg is not a known default key.

Examples

from arclm.configs import create_config, Config

# 1. Defaults + overrides
config = create_config(embed_dim=32, block_size=16, num_epochs=3, device="cpu")
print(config.embed_dim, config.block_size, config.device)

# 2. Direct construction
config = Config(embed_dim=64, block_size=32)

# 3. Inspect
print(config.to_dict()["learning_rate"])

# 4. Safe set (unknown keys ignored)
config.set_safe(device="cpu", not_a_real_key=1)

# 5. YAML round-trip (core install)
from arclm.configs import save_config_yaml, load_config_yaml
save_config_yaml(config, "arclm-config.yaml")
loaded = load_config_yaml("arclm-config.yaml")
assert loaded.embed_dim == config.embed_dim

When not to use Config

  • Use arclm.training.TrainingConfig for the modern Trainer API.
  • Use arclm.datasets.DatasetConfig for load_dataset options.
