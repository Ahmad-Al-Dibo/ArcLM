arclm.security core crypto needs [security]

Security-by-default helpers: redaction, path safety, hashing, encryption, signing, and status reporting. Operations fail closed when keys or optional crypto libraries are missing. When to use: logging pipelines, artifact storage, agent outputs, web hardening policies.

Redaction

redact_sensitive_text(text: str) -> str
Purpose Replace secret-like patterns (API keys, tokens) with [REDACTED].
When to use Before writing logs, traces, or user-visible error dumps.
When not Not a full DLP product; not encryption. Always test on your payload shapes.
Torch Not required.
# Verified
from arclm.security import redact_sensitive_text
print(redact_sensitive_text("use api_key=sk-test-1234567890 now"))
# use api_key=[REDACTED] now

print(redact_sensitive_text("token=ghp_abcdefghijklmnop"))
# token=[REDACTED]

# Practical: wrap every log write
import logging
log = logging.getLogger("app")
msg = redact_sensitive_text(user_input)
log.info(msg)
redact_mapping(data: Mapping) -> dict
Purpose Redact secret-like keys/values in nested mappings.

security_status()

security_status() -> dict
Purpose JSON-safe report of available security capabilities (signing, crypto, web flags).
When to use Startup logs, health endpoints, CLI arclm security status.
from arclm.security import security_status
status = security_status()
print(status.get("signing", {}).get("available"))

Safe paths and URLs

resolve_under_root(root, user_path) -> Path
Purpose Resolve a user-supplied path under a root; reject traversal.
Errors Security policy errors on escape attempts.
from pathlib import Path
from arclm.security.paths import resolve_under_root
safe = resolve_under_root(Path("/data/app"), "../../etc/passwd")  # raises
safe = resolve_under_root(Path("/data/app"), "subdir/file.txt")   # ok
