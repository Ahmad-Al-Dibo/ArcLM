arclm.finetuning needs [train] HF SFT needs [hf]

Supervised fine-tuning: record contracts, formatting, native full FT, and Hugging Face train_sft.

train_sft(...)

train_sft(model, dataset, output_dir, *, backend="huggingface", …) -> SFTTrainingResult
Purpose Fine-tune a causal LM on SFT JSONL (messages / prompt-completion / instruction).
Params model — HF id or path; dataset — JSONL path; backend — currently Hugging Face path; optional LoRA flags.
Requires [hf] stack; network for Hub models.
trust_remote_code Defaults to False.
from arclm.finetuning import train_sft

result = train_sft(
    model="Qwen/Qwen3-0.6B",
    dataset="sft.jsonl",
    output_dir="out/sft",
    backend="huggingface",
    use_lora=True,
    lora_r=8,
)
print(result.output_dir)

JSONL record shapes:

{"messages": [{"role": "system", "content": "..."},
              {"role": "user", "content": "..."},
              {"role": "assistant", "content": "..."}]}
{"prompt": "Question?", "completion": "Answer."}
{"instruction": "Do X", "input": "context", "output": "result"}

Record contract

get_sft_record_contract() validate_sft_records(records, contract=…) prepare_fine_tuning_dataset(records, config=…) fine_tune(...) # native workflow entry 
from arclm.finetuning import (
    get_sft_record_contract, validate_sft_records,
    prepare_fine_tuning_dataset, FineTuningConfig,
)
contract = get_sft_record_contract()
validate_sft_records(records, contract=contract)
prepared = prepare_fine_tuning_dataset(records, config=FineTuningConfig())

FineTuningConfig

Controls data formatting/labels (not the optimizer loop — that stays in TrainingConfig).
