arclm.logics core

Educational propositional logic: symbols, connectives, model checking, and knowledge bases. When to use: teaching logic, small formal demos. When not: production theorem proving.

Main types

  • Symbol — propositional variable
  • Sentence — formula AST
  • Not, And, Or, Implication, Biconditional
  • model_check — brute-force entailment helper
  • KnowledgeBase, EntailmentResult
  • create_symbols

Example

from arclm.logics import Symbol, Not, And, Or, Implication, model_check

p = Symbol("P")
q = Symbol("Q")
# Build formulas with operators; use model_check for entailment demos.
