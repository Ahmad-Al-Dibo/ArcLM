arclm.models needs [train]

Native GPT-style causal language model (ArcLM). Educational scale — not a competitive chat LLM. Importing this package without torch raises OptionalDependencyError.

class ArcLM

ArcLM(vocab_size, embed_dim=64, block_size=8, num_blocks=2, dropout=0.0)
Purpose Token + position embeddings → GPT blocks → LM head logits.
Params
  • vocab_size (int, required, > 0)
  • embed_dim (default 64)
  • block_size (default 8) — max sequence length
  • num_blocks (default 2)
  • dropout (default 0.0, in [0, 1))
Forward Input (batch, time) int tensor → logits (batch, time, vocab_size).
Errors ValueError for non-positive shapes, bad dropout, wrong input rank, empty batch, sequence longer than block_size, token ids out of range.
# Verified forward pass
import torch
from arclm.models import ArcLM

model = ArcLM(vocab_size=11, embed_dim=16, block_size=8, num_blocks=1)
ids = torch.tensor([[2, 3, 4]])
logits = model(ids)
print(tuple(logits.shape))        # (1, 3, 11)
print(model.get_num_parameters()) # e.g. 3531

# Validation examples
# ArcLM(vocab_size=0)           -> ValueError
# model(torch.zeros(3))         -> ValueError (need rank 2)
# model(torch.ones(1, 9))       -> ValueError if block_size=8

# Embeddings access
emb = model.get_input_embeddings()

Methods

  • forward(idx) / call — logits
  • get_input_embeddings() — embedding module
  • get_num_parameters() — total parameter count

AutoModel

AutoModel.from_config(config)
Purpose Build ArcLM from a Config-like object (vocab_size required; optional embed_dim, block_size, num_blocks, dropout).
AutoModel.from_name(name, **kwargs)
Purpose Build by name. Supported: "arclm", "causal_lm".
Errors ValueError for unknown names.
from arclm.models import AutoModel
from arclm.configs import create_config

config = create_config(vocab_size=32, embed_dim=16, block_size=8, num_blocks=1)
model = AutoModel.from_config(config)
model2 = AutoModel.from_name("arclm", vocab_size=32, embed_dim=16)
