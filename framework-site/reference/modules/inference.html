load_model(path, device=…)

load_model(path, device=…) -> LoadedModel
Purpose Load a native ArcLM training checkpoint for prediction.
Errors Checkpoint / file errors; missing torch → OptionalDependencyError.

load_any_model(source, **kwargs)

load_any_model(source: PathLike, **kwargs) -> ExternalLoadedModel
Purpose Load native or Hugging Face models behind one interface.
Params device="cpu", trust_remote_code=False (safe default), plus backend kwargs.
Requires torch; HF models need transformers ([hf] / [hf-inference]).
When not Not every Hub model is supported — test per model id.

ExternalLoadedModel

.predict(prompt, **generation_kwargs) -> str .generate(prompt, **generation_kwargs) -> str .chat(messages: Sequence[Mapping[str, str]], **kwargs) -> str .batch_predict(prompts, **kwargs) -> list[str]

.chat() uses the tokenizer—™s chat_template via apply_chat_template when present; otherwise a simple role: content fallback. 

# Verified with sshleifer/tiny-gpt2 on CPU (fixture weights)
from arclm.inference import load_any_model

model = load_any_model("sshleifer/tiny-gpt2", device="cpu", trust_remote_code=False)
out = model.predict("Hello", max_new_tokens=5)
print(repr(out))

reply = model.chat([{"role": "user", "content": "Hi"}], max_new_tokens=6)
print(repr(reply))

# Generation kwargs (typical)
model.predict("The capital of France is", max_new_tokens=8, temperature=0.2)
Output quality depends entirely on the checkpoint. tiny-gpt2 produces nonsense on purpose — it proves the API path.

from arclm.inference import load_model, Generator
