arclm.evaluation needs [train]

Metrics, evaluator loop, diagnostics, and report export. When to use: measure a trained native model on a loader. When not: software tests that only check “it runs“ — evaluation is about model quality, which needs careful data splits.

Evaluator

Evaluator(model, metrics=…, config=…) .evaluate(loader) -> result
Purpose Run metric objects over a DataLoader-like iterable.
Requires arclm[train].

Metrics

  • Accuracy
  • LossMetric
  • Perplexity

Export

  • export_metrics_to_json(result, path)
  • export_metrics_to_markdown(result, path)

Diagnostics

  • predict_top_k(model, tokenizer, text, k=…)
  • build_training_diagnostics_report(...)
  • score_concept_relationships, run_long_context_evaluation
  • Formatting helpers: format_top_k_predictions, format_tokenizer_coverage_report, …
