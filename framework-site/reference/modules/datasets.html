arclm.datasets core

Load, validate, clean, and deduplicate text records. Records are plain dict objects; the usual text key is "text". When to use: preparing local data for native training or inspection. DataLoader helpers that need torch are optional.

load_dataset(source, **kwargs)

load_dataset(source, **kwargs) -> list[dict] | StreamingDataset
Purpose Load records from a list, path (json/jsonl/csv/txt), or DatasetConfig.
Params source — list of dicts, file path string/Path, or DatasetConfig. Additional kwargs depend on format.
Returns List of record dicts, or a streaming dataset when streaming is enabled.
Errors DatasetLoadError and related dataset exceptions on bad input.
Torch Not required for loading lists/JSONL.
# 1. From a list (verified)
from arclm.datasets import load_dataset
records = load_dataset([
    {"text": "Hello world"},
    {"text": "ArcLM is light"},
])
print(len(records), records[0]["text"])

validate_records(records, *, required_fields, …)

validate_records(records, *, required_fields, field_types=None, allow_empty=False, strict=True, record_id_field=None) -> DatasetValidationResult
Purpose Check each record for required fields and types.
Params
  • required_fields — sequence of field names (keyword-only, required)
  • allow_empty — allow empty strings/lists (default False)
  • strict — strict schema enforcement
Returns Result with valid_count and issue details.
# Verified
from arclm.datasets import validate_records
records = [{"text": "ok"}, {"text": ""}]
result = validate_records(records, required_fields=["text"])
print(result.valid_count)
# empty text may be invalid unless allow_empty=True
result2 = validate_records(records, required_fields=["text"], allow_empty=True)
print(result2.valid_count)

deduplicate(dataset, *, return_result=False, **kwargs)

deduplicate(dataset, *, return_result: bool = False, **kwargs)
Purpose Remove exact duplicates via ExactDeduplicator.
Returns With return_result=True: DeduplicationResult with dataset, kept, removed, duplicate_keys.
# Verified
from arclm.datasets import deduplicate
recs = [
    {"text": "Hello world"},
    {"text": "Hello world"},
    {"text": "ArcLM is light"},
]
out = deduplicate(recs, return_result=True)
print("kept", out.kept, "removed", out.removed)  # kept 2 removed 1
print([r["text"] for r in out.dataset])

DataPipeline(steps)

Torch-dependent helpers

create_dataloader and TextDataset (sliding-window LM tensors) require PyTorch. They live in datasets.base with optional import fallbacks.
