arclm.exceptions core

Central error hierarchy. Root class: ArcLMError. Catch broad ArcLM failures with except ArcLMError, or narrow to domain errors when you can recover differently.

OptionalDependencyError

OptionalDependencyError(message)
Purpose Raised by require_torch() / require_optional_dependency() when an extra is missing.
Message Names the feature, the PyPI package, and the pip extra (e.g. arclm[train]).
from arclm.exceptions import OptionalDependencyError, ArcLMError

try:
    from arclm.models import ArcLM
except OptionalDependencyError as e:
    print(e)
    # arclm.models requires optional dependency 'torch'.
    # pip install "arclm[train]"

# Catch-all pattern
try:
    from arclm.training import train_model
    train_model(...)
except ArcLMError as e:
    print("ArcLM failed:", e)

When to use which

  • Library code: raise the most specific subclass.
  • Applications: catch OptionalDependencyError for install hints; catch domain errors for UX messages.
  • Do not catch bare Exception around training if you want CI to fail loudly.
