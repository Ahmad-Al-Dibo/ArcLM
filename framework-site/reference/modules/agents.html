arclm.agents core

Provider-independent agent runtime: typed tools, bounded runner, permissions, sessions, and traces. When to use: local tool-calling agents without a GPU. When not: when you only need a raw completion API — use inference instead.

@tool decorator

@tool(category="utilities", **options)
Purpose Wrap a Python function as a tool: docstring becomes the description; type hints become a JSON schema.
Params Function with typed parameters. Options: name, description, category, side_effect, permission, timeout_seconds, …
Returns A Tool object usable in a registry/agent.
# Verified pattern (examples/10_agents_tools)
from arclm.agents import tool

@tool(category="utilities")
def add_numbers(left: float, right: float) -> float:
    """Add two numbers and return the sum."""
    return left + right

# Registry
from arclm.agents import ToolRegistry
registry = ToolRegistry([add_numbers])
print(registry.get("add_numbers").description)

# Observed runner output (deterministic example adapter)
# {
#   "tool_calls": ["add_numbers"],
#   "output": "Done. The tool result was processed safely."
# }

Agent and AgentRunner

Agent(...)
Purpose Holds model adapter, tools, config, security policy.
AgentRunner
Purpose Bounded loop: model → tool calls → results → repeat until final response or step limit.
When to use Production-shaped agents with max steps and approvals.

Model adapters

Adapters translate agent messages to a model call and parse tool calls. Include callable adapters and JSON tool-calling adapters (arclm.agents.model).

Permissions and side effects

  • SideEffectLevel — none / read-only / network / write …
  • Default deny for risky tools unless an approval handler allows them
  • Traces can be redacted via SecurityPolicy.redact_traces

Built-in tools

  • arclm.agents.builtins.documents — markdown/HTML/text file readers (path-traversal safe)
  • arclm.agents.builtins.utilities — math/JSON helpers
  • arclm.agents.builtins.web — SafeWebReader (blocks private hosts)

Common mistakes

  • Omitting type hints → weak schema; always type parameters.
  • Unbounded loops → always set max steps / session limits.
  • Logging raw tool args with secrets → redact first.
