arclm.checkpoints needs [train]

Save, load, inspect, and adapt model checkpoints. When to use: durable training state, trusted reload, SmartLoader planning before a big load. When not: for untrusted pickle files from strangers — use the safe/trusted APIs only.

atomic_save_checkpoint

atomic_save_checkpoint(state, path, …) -> Path
Purpose Write via temp file + os.replace; validate before replace.
Errors CheckpointError on IO/validate failure.

safe_load_training_checkpoint

safe_load_training_checkpoint(path, map_location=…) -> dict
Purpose Trusted load path for ArcLM training checkpoints.
