arclm.tokenizers core

Word-level and SentencePiece tokenizers. When to use: any text → id pipeline for native ArcLM models or inspection. When not: when you need a Hugging Face tokenizer for an external model — use that model—™s tokenizer from transformers instead.

class Tokenizer

Tokenizer(max_vocab=50000, default_token="<UNK>", user_defined_symbols=None)
Purpose Whitespace word-level tokenizer with an inspectable vocabulary.
When to use Teaching, tiny corpora, debugging token ids.
When not Production multilingual subword needs — use SentencePiece.

Methods

build(text: str) -> None
Purpose Split on whitespace, count tokens, keep top max_vocab entries. Fills vocab, stoi, itos, token_counts.
Note Does not lowercase. "Arc" ——° "arc".
encode_text(text: str) -> list[int]
Purpose Whitespace-split then map via stoi; unknown → default token index.
encode(tokens: list[str]) -> list[int]
decode(indices: list[int]) -> list[str] decode_string(indices: list[int]) -> str
get_vocab_size() -> int get_unknown_index() -> int
to_checkpoint() -> dict
Purpose Serializable tokenizer metadata for ArcLM training checkpoints.

Examples

# 1. Minimal build + encode (verified)
from arclm.tokenizers import Tokenizer
text = "arc lm trains tiny models on local text about language models"
tok = Tokenizer(max_vocab=64)
tok.build(text)
print(tok.encode_text("arc lm trains"))  # [2, 3, 4]
print(tok.get_vocab_size())              # 11 on this corpus
print(tok.decode([2, 3, 4]))             # ['arc', 'lm', 'trains']

# 2. Unknown words map to <UNK>
ids = tok.encode_text("completely novel tokens here")
print(tok.decode(ids))  # mostly ['<UNK>', ...]

# 3. Case sensitivity
tok2 = Tokenizer(max_vocab=32)
tok2.build("Arc arc ARC")
print(tok2.encode_text("arc"), tok2.encode_text("Arc"))  # different ids

# 4. Save / load vocabulary
tok.save_vocab("vocab.txt")
tok2 = Tokenizer(max_vocab=64)
tok2.load_vocab("vocab.txt")

# 5. Coverage analysis
tokens = text.split()
stats = tok.analyze_coverage(tokens)
print(stats)  # unknown-rate / vocab coverage dict

class SentencePieceTokenizer

SentencePieceTokenizer(model_type="bpe", vocab_size=…, character_coverage=1.0, …)
Purpose Subword tokenizer via the sentencepiece library.
When to use Multilingual text, fewer UNKs, closer to production tokenization.
Requires sentencepiece (core dependency).
from arclm.tokenizers import SentencePieceTokenizer
sp = SentencePieceTokenizer(model_type="bpe", vocab_size=200)
sp.build("your corpus text ...")
ids = sp.encode_text("hello world", out_type=int)
print(ids)

    pass

TokenizerFactory.register("custom", MyTok)
t = TokenizerFactory.create("custom", max_vocab=16)
t2 = create_tokenizer("word", max_vocab=8)

Common mistakes

  • Building on one corpus then encoding OOD text → high UNK rate. Build on a representative sample.
  • Expecting automatic lowercasing — normalize yourself before build.
  • Using this tokenizer with an HF model — use the HF tokenizer for that model.
