arclm.search core

Naming: arclm.search is hyperparameter search (grid/random over training configs), not BM25/semantic information retrieval. Text search belongs in your application or a future retrieval module.

Overview

Search spaces, trial lifecycle, JSONL persistence, and comparison — built on arclm.tracking. Config types for training/fine-tuning are imported from light config modules so the search package stays importable without torch.

Public API (high level)

  • create_search — build a search from a space + objective
  • SearchSpace, parameter types (ChoiceParameter, IntegerParameter, …)
  • HyperparameterSearch, trial records, compare_trials
  • load_search, inspect_search, validate_search, list_searches
