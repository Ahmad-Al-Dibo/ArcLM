How the framework works

Complete workflows using real APIs. Prerequisites noted per workflow.

Workflow A — Data preparation (core only)

from arclm.datasets import load_dataset, validate_records, deduplicate
from arclm.tokenizers import Tokenizer

records = load_dataset("data.jsonl")  # or list of dicts
result = validate_records(records, required_fields=["text"])
print("valid", result.valid_count)

clean = deduplicate(records, return_result=True)
print("kept", clean.kept, "removed", clean.removed)

tok = Tokenizer(max_vocab=1000)
tok.build(" ".join(r["text"] for r in clean.dataset))
# ids for training later: [tok.encode_text(r["text"]) for r in clean.dataset]

Steps: load → validate → dedupe → tokenize. No torch. Errors: DatasetLoadError, validation issues.

Workflow B — Native tiny model (train extra)

# pip install "arclm[train]"
from arclm.configs import create_config
from arclm.training import train_model

config = create_config(embed_dim=32, block_size=16, num_epochs=1, device="cpu")
result = train_model(
    mode="pre_training",
    data="data.txt",
    output="models/tiny.pth",
    config=config,
)
print(result.history.get("train_losses", [None])[-1])

Steps: config → data file → train_model → checkpoint path. Alternative lower-level path: build ArcLM + Trainer.train_dataset. CLI equivalent: arclm train --data data.txt --device cpu.

Workflow C — HF inference (hf extra)

# pip install "arclm[hf]"
from arclm.inference import load_any_model

model = load_any_model("sshleifer/tiny-gpt2", device="cpu", trust_remote_code=False)
print(model.predict("Hello", max_new_tokens=5, temperature=0.7))
print(model.chat([{"role": "user", "content": "Hi"}], max_new_tokens=6))

Steps: load (downloads once) → predict/chat. First load can take tens of seconds; later loads use the HF cache. Chat uses tokenizer templates when available.

Workflow D — SFT smoke (hf extra)

from arclm.finetuning import validate_sft_records, get_sft_record_contract, train_sft

# records: JSONL with messages / prompt+completion / instruction
contract = get_sft_record_contract()
validate_sft_records(records, contract=contract)

result = train_sft(
    model="Qwen/Qwen3-0.6B",
    dataset="sft.jsonl",
    output_dir="out/sft",
    backend="huggingface",
    use_lora=True,
    lora_r=8,
)

Steps: prepare JSONL → validate contract → train_sft → output dir. Needs network/disk for Hub models. Start with tiny configs.

Workflow E — Agent with tools (core only)

from arclm.agents import tool, ToolRegistry

@tool(category="utilities")
def add_numbers(left: float, right: float) -> float:
    """Add two numbers."""
    return left + right

registry = ToolRegistry([add_numbers])

Workflow F — Secure logging (core + [security] for crypto)

from arclm.security import redact_sensitive_text, security_status

safe = redact_sensitive_text(user_supplied_log_line)
logger.info(safe)
print(security_status())

Workflow G — Experiment tracking

from pathlib import Path
from arclm.tracking import (
    create_run, RunConfig, RunOperation, RunStorageConfig,
    set_reproducible_seed, load_run_manifest,
)

set_reproducible_seed(42)
tracker = create_run(RunConfig(
    name="baseline",
    operation=RunOperation.TRAINING,
    storage=RunStorageConfig(root_directory=Path("runs"), fsync=False),
))
tracker.start()
tracker.record_metric(metrics={"loss": 2.0}, step=1)
tracker.complete({"final_loss": 2.0})
tracker.close()
manifest = load_run_manifest(tracker.run_dir)

Error handling across workflows

  • Missing extra → OptionalDependencyError with pip hint.
  • Bad data paths → DatasetLoadError.
  • Bad TrainingConfig → TrainingConfigError.
  • Empty checkpoint config → compatibility functions return False (no silent resume).
