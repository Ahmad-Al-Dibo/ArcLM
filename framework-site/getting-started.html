Getting started

System requirements

  • Python: 3.9 or newer (tested 3.9–3.14 on local venvs and CI light matrix)
  • OS: Linux, Windows, macOS (developed on Windows; CI on Ubuntu)
  • Hardware: CPU sufficient for core + tiny native models; GPU optional
  • Disk: ~50 MB core; hundreds of MB if you add torch; GBs if you download large HF models

Installation

Minimal (no PyTorch)

python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install arclm
python -c "import arclm; print(arclm.get_version())"

Required packages: numpy, sentencepiece.

Training stack

pip install "arclm[train]"
# CPU-only torch first if preferred:
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install "arclm[train]"

Hugging Face inference

pip install "arclm[hf]"

First working result (core only)

from arclm.tokenizers import Tokenizer
from arclm.configs import create_config
from arclm.security import redact_sensitive_text

config = create_config(embed_dim=32, block_size=16, device="cpu")
tok = Tokenizer(max_vocab=64)
tok.build("arc lm trains tiny models on local text about language models")
print(tok.encode_text("arc lm trains"))  # e.g. [2, 3, 4]
print(redact_sensitive_text("api_key=sk-test-123"))  # api_key=[REDACTED]

First native forward pass (needs [train])

import torch
from arclm.models import ArcLM
from arclm.tokenizers import Tokenizer

text = "arc lm trains tiny models on local text about language models"
tok = Tokenizer(max_vocab=64)
tok.build(text)
model = ArcLM(vocab_size=tok.get_vocab_size(), embed_dim=16, block_size=8, num_blocks=1)
ids = torch.tensor([tok.encode_text("arc lm trains")[:8]])
print(tuple(model(ids).shape))  # (1, 3, 11) on this corpus

CLI health check

arclm --version
arclm doctor

doctor prints Python, torch (if any), CUDA, and optional dependency status. It does not require torch.

Configuration basics

arclm.configs.Config / create_config store model size, paths, device, and tokenizer type. Persist with save_config_yaml / load_config_yaml. Device defaults to "cpu". Use arclm.tracking.set_reproducible_seed to seed RNGs (config creation does not seed torch).
