Models and training needs [train]

Native ArcLM model

What: GPT-style causal LM (embeddings → transformer blocks → LM head). Why: a model small enough to read and run in seconds on CPU. Limit: educational scale — not a competitive chat model. 

import torch
from arclm.models import ArcLM, AutoModel

model = ArcLM(vocab_size=64, embed_dim=16, block_size=8, num_blocks=1)
logits = model(torch.tensor([[1, 2, 3]]))
print(tuple(logits.shape), model.get_num_parameters())

model2 = AutoModel.from_config(config)  # config.vocab_size required

Config options: embed_dim, block_size, num_blocks, dropout. Errors: ValueError on bad shapes, sequence longer than block_size, out-of-range token ids.

Trainer and TrainingConfig

from arclm.training import Trainer, TrainingConfig

tcfg = TrainingConfig(epochs=5, batch_size=8, precision="fp32", optimizer="adamw")
trainer = Trainer(model=model, config=tcfg)
# history = trainer.train_dataset(train_loader, val_loader=val_loader)

Why TrainingConfig ≠ Config: trainer fields are validated (precision, optimizer names, positive epochs). Use arclm.configs.Config for data paths and model shape in the high-level train_model path.

One-call train_model

from arclm.configs import create_config
from arclm.training import train_model

result = train_model(
    mode="pre_training",  # or fine_tuning / instruction_tuning
    data="data.txt",
    output="models/out.pth",
    config=create_config(device="cpu", num_epochs=1),
)

Checkpoint compatibility

  • checkpoint_is_compatible_for_continue_training — strict: vocab, shape, tokenizer, training hyperparameters; empty config → False.
  • checkpoint_is_compatible_for_tuning — allows different learning rate; still requires shape + tokenizer; empty config → False.

Regularization utilities

L1/L2, EarlyStopping, LearningRateScheduler, LabelSmoothing, MixupAugmentation, GeneralizationMonitor in arclm.training.regularization.

GPU

config = create_config(device="cuda")  # fails loud if no CUDA
# or device="auto" where resolve helpers support it
arclm train --data data.txt --device cuda

Install CUDA torch wheel first, then arclm[train]. Verify with arclm doctor. Multi-GPU: experimental contracts in arclm.distributed.
