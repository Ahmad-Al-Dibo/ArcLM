Current direction (summary)

The project is consolidating a clean 2.0: light install, honest documentation, CI that enforces the torch boundary, and a publishable PyPI package. After that, the highest-leverage gaps are retrieval/RAG primitives, multilingual examples, and deepening verified HF/SFT paths — all currently labeled Proposed or Planned, not implemented commitments.

Biggest remaining risks: discoverability vs similarly named packages; keeping docs synchronized with a multi-package codebase; avoiding over-claiming experimental distributed/QLoRA support.
