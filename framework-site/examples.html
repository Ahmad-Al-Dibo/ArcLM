Beginner

B1 — Tokenizer round-trip

Objective: see text → ids → text. Needs: core.

from arclm.tokenizers import Tokenizer
text = "arc lm trains tiny models on local text about language models"
tok = Tokenizer(max_vocab=64)
tok.build(text)
ids = tok.encode_text("arc lm trains")
print(ids, tok.get_vocab_size(), tok.decode(ids))
# Observed: [2, 3, 4] 11 ['arc', 'lm', 'trains']

Modify: change max_vocab; encode out-of-vocab words.

Mistake: expecting automatic lowercase — it does not lowercase.

Developer

D1 — Validate and dedupe before training

from arclm.datasets import load_dataset, validate_records, deduplicate
records = load_dataset([{"text": "A"}, {"text": "A"}, {"text": "B"}])
assert validate_records(records, required_fields=["text"]).valid_count == 3
out = deduplicate(records, return_result=True)
assert out.kept == 2 and out.removed == 1

Advanced

A1 — Tracking run + compare

from pathlib import Path
from arclm.tracking import create_run, RunConfig, RunOperation, RunStorageConfig, compare_runs
tracker = create_run(RunConfig(
    name="adv", operation=RunOperation.TRAINING,
    storage=RunStorageConfig(root_directory=Path("runs-adv"), fsync=False),
))
tracker.start()
tracker.record_metric(metrics={"loss": 1.5}, step=1)
tracker.complete({})
tracker.close()
print(compare_runs([tracker.run_dir], metric_name="loss").metric_summary)
