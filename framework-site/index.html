ArcLM

ArcLM is a compact Python toolkit for language-model data workflows, tokenizers, optional PyTorch training, Hugging Face inference, agents, and security. The core install is light; PyTorch is an extra, not a requirement.

What ArcLM does

  • Load, validate, clean, and deduplicate local text datasets.
  • Tokenize with word-level or SentencePiece models.
  • Train a native tiny GPT-style model (optional torch).
  • Load Hugging Face causal LMs behind one interface and generate text.
  • Fine-tune with supervised fine-tuning (SFT), including optional LoRA.
  • Evaluate with accuracy / loss / perplexity and export reports.
  • Run bounded tool-calling agents without a GPU.
  • Redact secrets, encrypt/sign artifacts, and audit security status.
  • Track local experiments (runs, metrics, seeds) without a cloud service.

Intended audience

  • Educators and students — laptop, limited bandwidth, no GPU cluster.
  • Application developers — HF loading, agents, data pipelines, security helpers.
  • Researchers — embed a light toolkit; train only when the experiment needs it.

Design principles

  1. Light by default. import arclm must not import torch.
  2. Readable source. Packages small enough to study; no 10k-line trainer as the only path.
  3. Honest limits. The native model is educational; docs and examples say so.
  4. Fail closed in security paths; clear OptionalDependencyError for missing extras.
  5. Verified examples. The maintained suite runs offline on CPU.

How it differs (carefully)

  • vs Hugging Face transformers alone: ArcLM loads HF models but also ships tokenizers, data tools, a tiny native model, agents, and security with a light core. It is not a replacement for the HF model zoo.
  • vs large training frameworks: no production multi-GPU serving stack; the native trainer is intentionally small and readable.
  • vs notebook-only tutorials: versioned PyPI package, CLI, tests, CI, security layer.

What you can realistically accomplish

  • Install in seconds and tokenize/validate data immediately.
  • Load a small public HF model and generate text on CPU.
  • Run a tiny native training smoke test in seconds.
  • Build a local agent with typed tools and no API key (example adapter).
  • Integrate redaction and signed manifests into your own logging/artifacts.

What it is not

  • Not a competitive general-purpose chat LLM by itself.
  • Not a replacement for Hugging Face as a model hub client.
  • Not a production multi-node training or serving platform.
  • Not a guarantee of quality for any specific Hub model — compatibility is per model.

How to use this site
