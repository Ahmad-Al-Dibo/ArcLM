ArcLM

ArcLM is een compacte Python-toolkit voor taalmodel-workflows: data, tokenizers, optionele PyTorch-training, Hugging Face-inferentie, agents en beveiliging. De kerninstallatie is licht; PyTorch is een extra, geen vereiste.

Wat ArcLM doet

  • Lokale tekst-datasets laden, valideren, opschonen en dedupliceren.
  • Tokenizen met word-level of SentencePiece-modellen.
  • Trainen van een native mini-GPT (optioneel torch).
  • Hugging Face causale modellen laden achter één interface en tekst genereren.
  • Fine-tuning met supervised fine-tuning (SFT), inclusief optionele LoRA.
  • Evalueren met accuracy / loss / perplexity en rapportages exporteren.
  • Gebonden tool-calling agents draaien zonder GPU.
  • Geheimen verbergen, artefacten versleutelen/ondertekenen en security-status auditen.
  • Lokale experiment-run tracking (runs, metrics, seeds) zonder clouddienst.

Problemen die het oplost

ProbleemAntwoord van ArcLM
Installeren “om even een API te proberen” trekt honderden megabytes Kerninstallatie is alleen NumPy + SentencePiece; torch achter [train]
Documentatie gaat uit van GPU + multi-GB downloads op dag één CPU-first voorbeelden; verified suite heeft geen netwerk of GPU nodig
Onduidelijk hoe data → tokens → model → eval in elkaar zit Kleine leesbare pakketten; inspect_text pipeline-traces
Educatiecode en applicatiecode leven in werelden Zelfde package voor Lab-scripts en app-ontwikkeling

Doelgroep

  • Docenten en studenten — laptop, beperkte bandbreedte, geen GPU-cluster.
  • App-ontwikkelaars — HF-laden, agents, data-pipelines, security-helpers.
  • Onderzoekers — lichte toolkit inembedden; alleen trainen als het experiment dat vraagt.

Ontwerpprincipes

  1. Licht als default. import arclm mag geen torch importeren.
  2. Leesbare bron. Pakketten klein genoeg om te studeren; geen 10k-regels trainer als enige pad.
  3. Eerlijke grenzen. Het native model is educatief; docs en voorbeelden zeggen dat ook.
  4. Fail closed in beveiligingspaden; duidelijke OptionalDependencyError bij ontbrekende extras.
  5. Geverifieerde voorbeelden. De maintained suite draait offline op CPU.

Hoe het zich onderscheidt (voorzichtig)

  • vs Hugging Face transformers alleen: ArcLM laadt HF-modellen maar levert ook tokenizers, data-tools, een tiny native model, agents en security met een lichte kern. Het is geen vervanging voor de HF-modelbibliotheek.
  • vs grote trainingsframeworks: geen productie multi-GPU serving-stack; de native trainer is bewust klein en leesbaar.
  • vs alleen notebooks: versieerd PyPI-pakket, CLI, tests, CI, security-laag.

Wat je realistisch kunt bereiken

  • In seconden installeren en meteen data valideren en tokenizen.
  • Een klein publiek HF-model laden en op CPU tekst genereren.
  • Een tiny native trainings-smoketest draaien in seconden.
  • Een lokale agent bouwen met getypeerde tools en zonder API-key (voorbeeldadapter).
  • Redactie en ondertekende manifests integreren in je eigen logging/artefacten.

Wat het niet is

  • Geen competitieve algemene chat-LLM op zichzelf.
  • Geen vervanging van Hugging Face als model-hub-client.
  • Geen productie multi-node trainings- of servingplatform.
  • Geen kwaliteitsgarantie voor een specifiek Hub-model — compatibiliteit is per model.
