Agents and security core

Agent runtime

What: provider-independent tool-calling loop. Why: structured tools with schemas, permissions, and bounded steps — without requiring a GPU or a specific LLM vendor. Modules: arclm.agents. 

from arclm.agents import tool

@tool(category="utilities")
def add_numbers(left: float, right: float) -> float:
    """Add two numbers."""
    return left + right

# Runnable example:
# python examples/10_agents_tools/01_custom_tool_agent.py
# Observed: {"tool_calls": ["add_numbers"], "output": "Done. …"}

Components: Tool / @tool, ToolRegistry, Agent, AgentRunner (max steps), model adapters, sessions, traces, approvals, SideEffectLevel.

Builtins: document readers (safe paths), math/JSON utilities, SafeWebReader (blocks private hosts). Whisper STT optional via [agents-audio].

Limits: example uses a deterministic adapter (no API key). Production adapters plug in your model. Approvals default-deny risky side effects.

Security core

What: redaction, safe paths, hashing, AEAD crypto, manifest signing, status reporting. Why: local AI apps log prompts and store artifacts — secrets leak without tooling. Modules: arclm.security. 

from arclm.security import redact_sensitive_text, security_status

print(redact_sensitive_text("use api_key=sk-test-1234567890"))
# use api_key=[REDACTED]
print(security_status())

Full crypto needs arclm[security] (cryptography). Encrypt/decrypt, Argon2id key derivation, sign/verify manifests, encrypted artifact stores. Fail-closed: missing keys or libraries raise — they do not silently skip. 

# CLI
arclm security status --json
arclm security audit

How agents use security

Agents import SecurityPolicy from arclm.security.configuration (not the package root) so the agents Block stays free of the full crypto stack. Traces can redact sensitive text via policy flags.
