Native generation

from arclm.inference import load_model

model = load_model("models/tiny.pth")
print(model.predict("the future is", max_new_tokens=20, temperature=0.8))

Sampling options: temperature, top_k, top_p, repetition_penalty. Quality depends entirely on the checkpoint — tiny native models will not write useful prose.

Hugging Face models

from arclm.inference import load_any_model

model = load_any_model(
    "sshleifer/tiny-gpt2",
    device="cpu",
    trust_remote_code=False,  # safe default
)
print(model.predict("Hello", max_new_tokens=5))
print(model.chat([{"role": "user", "content": "Hi"}], max_new_tokens=6))

Chat templates: if the tokenizer defines chat_template, ArcLM uses apply_chat_template; otherwise a simple role: content fallback. Limit: not every Hub model is supported — test per model. Verified: tiny-gpt2 load ~39s cold, generate ~1s on CPU (fixture weights; output is intentionally nonsense).
