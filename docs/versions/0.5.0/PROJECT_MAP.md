# ArcLM 0.5.0 Projectkaart

Dit bestand is een archiefpagina voor de oude `0.5.0` documentatie.

De actuele code gebruikt nu vooral de `src/arclm` package-structuur. Nieuwe documentatie staat in:

- `README.md`
- `docs/special-version.md`
- `docs/roadmap.md`
- `docs/data/`
- `docs/architecture/`

## Belangrijk

Deze werkmap beschrijft nu de speciale ArcLM-versie. Dat is geen open-source release. Het is een private/speciale versie waarin ook advanced onderdelen mogen komen.

## Huidige Hoofdlijnen

| Onderdeel | Huidige plek |
| --- | --- |
| Configs | `src/arclm/configs` |
| Models | `src/arclm/models` |
| Tokenizers | `src/arclm/tokenizers` |
| Datasets | `src/arclm/datasets` |
| Training | `src/arclm/training` |
| Inference | `src/arclm/inference` |
| Checkpoints en loaders | `src/arclm/checkpoints` en `src/arclm/loaders` |
| Oude import-compatibiliteit | meerdere kleine shim-modules |

## Waarom Dit Archief Kort Is

De oude projectkaart was lang en beschreef de vroegere publieke `0.5.0` baseline. Dat is niet meer de beste startplek voor deze speciale versie.

Gebruik de actuele docs hierboven als bron van waarheid.
