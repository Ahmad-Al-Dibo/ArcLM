## Wat Was Belangrijk In 0.5.0?

- Native ArcLM training.
- Word en SentencePiece tokenizers.
- DataProcessor workflow.
- JSONL preprocessing.
- Hugging Face SFT basis.
- Checkpoint loading en eenvoudige diagnostics.

## Let Op

De huidige werkmap beschrijft de speciale ArcLM-versie. Die versie is niet bedoeld als open-source release. Oude 0.5.0 documenten zijn alleen handig om historische keuzes terug te lezen.
