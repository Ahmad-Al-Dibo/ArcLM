## Huidige Richting

De speciale ArcLM-versie gebruikt een `src/` layout, domain packages en Nederlandse studentgerichte documentatie. De datasetlaag heeft nu een moderne API met:

- `load_dataset`
- `DatasetLoader`
- `DataPipeline`
- cleaning stappen
- `ExactDeduplicator`
- streaming basis

Deze versie is niet bedoeld als open-source release.
