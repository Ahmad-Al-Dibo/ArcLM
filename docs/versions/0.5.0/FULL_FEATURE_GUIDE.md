# ArcLM 0.5.0 Featuregids

Dit is een korte archiefpagina voor de oude volledige featuregids.

De oude gids is niet meer de beste bron voor de huidige speciale ArcLM-versie. De code is verder gegaan met een duidelijkere `src/arclm` structuur en een nieuwe dataset API.

## Status Van Deze Versie

Deze ArcLM-versie is speciaal en niet open-source. Hier mogen advanced features worden toegevoegd, zolang de basis simpel en leerbaar blijft.
