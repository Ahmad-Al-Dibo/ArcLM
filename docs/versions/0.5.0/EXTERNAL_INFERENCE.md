# Externe Inference Archief

Dit is een archiefpagina voor externe inference documentatie uit ArcLM 0.5.0.

Voor actuele inference code gebruik je:

```python
from arclm.inference import load_model, load_any_model, predict
from arclm.checkpoints import SmartLoader
```

## Korte Uitleg

ArcLM kan native checkpoints laden en heeft helpers om modelbronnen te inspecteren. In de speciale versie mag dit later verder groeien naar advanced model-source tooling, lokale serving en dashboards.

Deze pagina is alleen archief. Gebruik de hoofddocumentatie voor nieuwe code.
