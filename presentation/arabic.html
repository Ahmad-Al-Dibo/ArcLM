الخطوة 1 · مقدمة

ما المشكلة التي تحلّها ArcLM؟

  • التثبيت «لتجربة API» يسحب مئات الميغابايت
  • التوثيق يفترض GPU + تنزيلات ضخمة من اليوم الأول
  • صعب قراءة كيف تتناغم البيانات ← الرموز ← النموذج ← التقييم
  • الأكواد التعليمية و prod يعيشان في عالمين منفصلين

ما نريده

  • تثبيت في ثوانٍ على لابتوب
  • نتيجة مفيدة قبل أي تدريب
  • PyTorch اختياري وليس إلزامياً
  • الكود صغير بما يكفي للدراسة
  • نفس الحزمة للتعليم وبناء التطبيقات

الخطوة 2 · تجربة النواة

جرّب: Tokenizer + Config (بدون GPU)

from arclm.tokenizers import Tokenizer
from arclm.configs import Config

text = "arc lm trains tiny models on local text"
tok = Tokenizer(max_vocab=64)
tok.build(text)

print(tok.encode_text("arc lm trains"))
print(tok.get_vocab_size())
print(tok.decode([2, 3, 4]))

cfg = Config(embed_dim=32, block_size=16, device="cpu")
print(cfg.embed_dim, cfg.block_size, cfg.device)
المخرجات الفعلية (مُختبرة)
[2, 3, 4] 11 ['arc', 'lm', 'trains'] 32 16 cpu

لا يوجد تحويل تلقائي لحالة الأحرف — Arc ≠ arc.

انتبه: هذه النواة تعمل على أي جهاز بدون GPU.

الخطوة 3 · تجربة نموذج أصلي

أنشئ نموذجاً صغيراً وشغّل forward

import torch
from arclm.models import ArcLM

model = ArcLM(
    vocab_size=11, embed_dim=16,
    block_size=8, num_blocks=1,
)
ids = torch.tensor([[2, 3, 4]])
logits = model(ids)

print(tuple(logits.shape))
print(model.get_num_parameters())
المخرجات الفعلية

الخطوة 4 · GPU

ثالثاً: التدريب على GPU (إن وُجد)

# 1) ثبّت CUDA torch أولاً
pip install torch --index-url https://download.pytorch.org/whl/cu124
pip install "arclm[train]"

# 2) تحقق أن ArcLM يرى البطاقة
arclm doctor

# 3) استخدم cuda في الكود أو CLI
from arclm.configs import create_config
config = create_config(device="cuda")  # أو "auto"

arclm train --data data.txt --device cuda
doctor عند توفر GPU
CUDA available: True CUDA version: 12.4 GPU count: 1 GPU name: NVIDIA ... Current device: cuda:0

ملاحظات مهمة

  • auto ← CUDA إن وُجد وإلا CPU
  • cuda ← فشل صريح إذا لا GPU
  • دقّة: fp32 / fp16 / bf16
  • Multi-GDP: تجريبي — لا تبالغ
بدون GPU؟ كل ما عرضناه يعمل على CPU — GPU تسريع وليس شرطاً.

داخل النواة

ما داخل كل حزمة أساسية؟

configs + tokenizers

  • Config كائن Python عادي
  • حفظ/تحميل YAML و JSON
  • Tokenizer على مستوى الكلمة
  • SentencePiece BPE
  • مصنع + تسجيل أنواع مخصصة

datasets

  • load_dataset — قائمة/JSONL/CSV
  • validate_records — حقول مطلوبة
  • deduplicate — إزالة التكرار
  • DataPipeline — خطوات تنظيف
  • Streaming للملفات الكبيرة

agents + security + tracking

  • @tool → schema تلقائي
  • حلقة محدودة + صلاحيات
  • تشفير AEAD · توقيع · إخفاء
  • سجلات تشغيل محلية
  • تجربة قابلة للتكرار (seeds)
مبدأ التصميم: كل حزمة مقروءة بمفردها — لا حالة عامة مخفية.

تجربة إضافية

SentencePiece + التحقق من السجلات

from arclm.tokenizers import SentencePieceTokenizer
sp = SentencePieceTokenizer(
    model_type="bpe", vocab_size=200)
sp.build("hello world arc lm ...")
print(sp.encode_text("hello world"))

from arclm.datasets import validate_records
r = validate_records(
    [{"text": "ok"}],
    required_fields=["text"],
)
print("valid_count", r.valid_count)

مقارنة صادقة

ArcLM مقابل مكدّسات شائعة

مقابل Hugging Face فقط

  • HF = مكتبة نماذج + تبعيات ثقيلة
  • ArcLM يحمّل HF ويشرح المسار
  • مكمّل لا بديل

مقابل أطر التدريب الكبيرة

  • لا stack إنتاج multi-node
  • نموذج صغير عن قصد
  • Trainer مقروء

مقابل دفاتر الملاحظات فقط

  • حزمة حقيقية + CLI + CI
  • أمان + وكلاء مضمّنين
  • منشور على PyPI

الحدود

ما الذي يقدّمه ArcLM — وما الذي لا يدّعيه

✓ يقدّم

  • تثبيت خفيف ~50 MB
  • Tokenize / validate / dedupe
  • تحميل نماذج HF وتوليد نص
  • تدريب نماذج أصلية صغيرة
  • Fine-tune (SFT / LoRA)
  • وكلاء بأدوات مكتوبة
  • إخفاء/تشفير/توقيع
  • تقييم وتصدير مقاييس
  • CLI + Studio محلي

✗ لا يدّعي

  • منافسة ChatGPT / Claude
  • جودة نثر من النموذج الأصلي الصغير
  • كل نماذج Hub تعمل (اختبر كل نموذج)
  • إنتاج multi-GPU جاهز
  • استبدال Hugging Face كمكتبة نماذج
  • ضمانات جودة للّغة العربية تحديداً

الجودة

كيف نحافظ على صدق الادّعاءات

  • CI خفيف — torch محجوب عند الاستيراد على Python 3.9–3.14
  • أمثلة مُتحقَّق منها — CPU محلي بدون شبكة

  • النموذج الصغير ≠ LLM تنافسي — مذكور في كل مسار تعليمي
