# Changelog

## 0.5.0

ArcLM 0.5.0 is the public baseline release for the refreshed package.

Highlights:

- Added a polished public README for PyPI and GitHub.
- Documented the supported native training, continued training, fine-tuning, and Hugging Face SFT workflows.
- Standardized the project name as ArcLM and the import package as `arclm`.
- Added a numbered, runnable examples directory focused on one concept per script.
- Clarified provider support: native checkpoints and Hugging Face SFT are supported; hosted LLM API providers are not built in.
- Improved package metadata, optional extras, classifiers, keywords, and project URLs.
- Made package imports quiet by default and added `report_environment()` for explicit diagnostics.
- Set the package version baseline to `0.5.0`.
